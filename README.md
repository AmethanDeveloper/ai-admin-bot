# Демо-бот «ИИ-администратор» для образовательного центра

Telegram-бот для вымышленной школы BrightWay English. Его показываем владельцам центров на встречах.

Что умеет:

- рассказывает о курсах, ценах, адресе и графике;
- записывает на бесплатный пробный урок: кто учится → курс → время → имя → телефон;
- перед записью спрашивает согласие на обработку персональных данных;
- присылает администратору каждую заявку и каждый вопрос, на который не нашёл ответа;
- напоминает о пробном уроке за 24 и за 2 часа; клиент нажимает «Приду» или «Перенести»;
- отвечает на свободные вопросы через Claude, если указан ключ API; без ключа ищет ответ в FAQ, а остальное пересылает администратору.

## Запуск

**Windows:** дважды щёлкните `start.bat`. При первом запуске он сам создаст окружение и установит библиотеки — это около минуты. Нужен Python 3.9 или новее.

**macOS / Linux:**

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

При первом запуске окно попросит вставить токен бота от @BotFather и сохранит его в `.env`. Дальше вводить его не нужно.

Первый, кто напишет боту `/start`, становится администратором: ему приходят заявки и вопросы клиентов. Его ID сохраняется в `admin_chat.txt`. Чтобы сменить администратора, удалите этот файл или укажите ID в `ADMIN_CHAT_ID=` в `.env`.

Бот работает, пока открыт терминал. Для показа владельцу этого достаточно; для клиентов позже перенесём бота на сервер.

## ИИ-ответы (необязательно)

1. Зарегистрируйтесь на platform.claude.com, пополните баланс на $5 и создайте API-ключ.
2. Вставьте ключ в `ANTHROPIC_API_KEY=` в `.env` и перезапустите бота.

Модель по умолчанию — `claude-haiku-5-5`, самая дешёвая. При ~2 000 вопросов в месяц расход около $1. Бот отвечает только по данным из `school.json`. Если ответа там нет (скидки, жалобы, особые условия), он пересылает вопрос администратору.

## Команды администратора

Работают только в чате с ID из `ADMIN_CHAT_ID`.

| Команда | Что делает |
| --- | --- |
| `/leads` | Последние 10 заявок |
| `/export` | Все заявки файлом CSV — открывается в Excel и Google Таблицах |
| `/reply 123456 текст` | Ответить клиенту от имени бота; ID приходит в уведомлении о вопросе |
| `/myid` | Показать ID текущего чата |

## Как адаптировать под клиента

Всё о школе лежит в `school.json`: название, адрес, график, курсы и цены, время пробных уроков, сколько человек помещается в один слот, частые вопросы. Под нового клиента копируете файл, меняете данные и указываете его в `SCHOOL_FILE=`. Код при этом не трогаете.

Время в боте — по Астане (UTC+5), задаётся полем `utc_offset`.

## Сценарий показа владельцу (2 минуты)

1. Дайте владельцу свой телефон с открытым ботом.
2. Попросите спросить что-нибудь своими словами, например: «Сколько стоит английский для ребёнка 9 лет?» или «Есть ли онлайн?»
3. Попросите записаться на пробный урок. Покажите, что уведомление пришло «администратору» через секунду.
4. Скажите: «То же самое будет работать в вашем WhatsApp, с вашими курсами и ценами, и в 23:00, и в воскресенье».

## Данные и безопасность

- Заявки хранятся в файле `leads.db` рядом с ботом. Это персональные данные клиентов: не пересылайте файл и не выкладывайте его в публичный доступ.
- Файл `.env` содержит токен и ключи — никому его не отправляйте. Если токен утёк, выпустите новый через @BotFather (`/revoke`).
- `.gitignore` уже исключает `.env` и базу из репозитория.
